GIF TUBE 2.2.7 — Felexwerd

В GifTube добавлены поиск GIF, избранное, бесконечная подгрузка и отображение GIF в комментариях YouTube у пользователей расширения.

НОВОЕ В 2.2.7
• Проверка обновлений через update.json на GitHub.
• Плашка на YouTube, если доступна новая версия.
• Кнопки «Скачать» и «Позже».
• Проверка при открытии YouTube и примерно раз в 6 часов.
• Проверка обновлений выполняется в service worker и не блокирует основные функции.

УСТАНОВКА
1. Скачайте ZIP-релиз и распакуйте его.
2. Откройте chrome://extensions/ или edge://extensions/.
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение» и выберите папку с manifest.json.
5. Перезагрузите YouTube.

УВЕДОМЛЕНИЕ НЕ УСТАНАВЛИВАЕТ ОБНОВЛЕНИЕ САМОСТОЯТЕЛЬНО. Оно открывает страницу GitHub Releases. Для распакованной версии нужно скачать архив, заменить файлы и нажать «Обновить» на карточке расширения. Владелец проекта должен прикреплять ZIP к каждому релизу.

ОГРАНИЧЕНИЕ YOUTUBE
Нативное прикрепление GIF зависит от YouTube. GifTube использует текстовый маркер со скрытой ссылкой. GIF отображается анимацией у зрителей с совместимым расширением; без расширения может отображаться только метка GIF.
