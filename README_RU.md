# GifTube 2.2.7 — Felexwerd

Расширение для поиска GIF, избранного, бесконечной подгрузки и отображения GIF в комментариях YouTube у пользователей GifTube.

## Новое в 2.2.7
- Проверка обновлений через update.json в этом репозитории.
- Компактное уведомление на YouTube, если опубликована более новая версия.
- Кнопка скачивания открывает страницу GitHub Releases; «Позже» скрывает уведомление для текущей версии.
- Проверка при открытии YouTube и затем примерно раз в 6 часов.
- Ошибка сети при проверке обновлений не влияет на поиск GIF и работу YouTube.

## Установка
1. Скачайте ZIP-архив релиза и распакуйте его.
2. Откройте chrome://extensions/ или edge://extensions/.
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение» и выберите папку с manifest.json.
5. Перезагрузите вкладку YouTube.

Для обновления распакованной сборки замените файлы папки новой версией и нажмите «Обновить» на карточке расширения либо загрузите новую папку после удаления старой сборки.

## Важно
Уведомление сообщает о новой версии, но не устанавливает её автоматически: Chrome и Edge не позволяют обычному расширению незаметно заменять распакованную сборку. Для работы кнопки скачивания владелец проекта должен прикреплять ZIP к каждому GitHub Release.

Нативное прикрепление GIF зависит от YouTube. GifTube передаёт GIF-ссылку в совместимом текстовом формате; анимация автоматически отображается у зрителей с совместимой версией GifTube. Без расширения пользователь может увидеть только метку GIF.
